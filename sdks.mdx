---
title: "SDKs"
description: "Official AI GIF Maker clients in ten languages, all with the same generate, submit, status and credits calls."
---

Every SDK has the same four calls: `generate(prompt)` submits, waits and returns the GIF URL; `submit(prompt)` returns a task id; `status(id)` returns where it stands; `credits()` returns the balance (free). All read `AIGIFMAKER_API_KEY` (create a key at https://aigifmaker.ai/settings/apikeys), poll every 3 seconds, and raise the same errors: `AuthError` (wrong or missing key), `QuotaError` (out of credits), `RejectedError` (prompt refused) and a base `AigifmakerError`.

## Python

```python
from aigifmaker import generate, credits

print(credits())  # credits left, free to call
print(generate("a corgi in sunglasses dancing on a beach"))  # GIF URL
```

## JavaScript / TypeScript

```js
import { generate } from "aigifmaker";

console.log(await generate("a paper plane looping over a city skyline at sunset"));
```

## Go

```go
url, err := aigifmaker.Generate(ctx, "a cat dancing in the rain, pixel art")
```

Each GIF costs 1 credit on your AI GIF Maker account, the same as on the website. New accounts get one free GIF (it carries a small aigifmaker.ai badge). Credits and plans are on the [pricing](https://aigifmaker.ai/pricing?utm_source=mintlify&utm_medium=docs) page.

Writing your own client: the [HTTP API](/http-api) is three calls. From an agent instead of code: the [MCP server](/mcp-server).
